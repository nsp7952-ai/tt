Способ 1: Личный Chat ID (рекомендуется для начала)

  1. Откройте Telegram и найдите бота @userinfobot
  2. Нажмите /start или отправьте любое сообщение
  3. Бот покажет ваш Id (например: 123456789)
  4. Скопируйте это число в поле выше

Способ 2: Через getUpdates API (для продвинутых)

  1. Создайте бота через @BotFather и получите токен
  2. Отправьте любое сообщение вашему новому боту
  3. Откройте в браузере:
    https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
  4. Найдите в ответе JSON поле "chat":{"id":...}
  5. Для личного чата ID положительный, для группы — отрицательный

Способ 3: Для группы/канала

  1. Добавьте вашего бота-алертера в группу/канал (сделайте администратором если нужно)
  2. Отправьте любое сообщение в эту группу
  3. Используйте Способ 2 с /getUpdates
  4. Найдите ID вашей группы (будет с префиксом -100 для каналов или просто отрицательный для групп)
  5. Пример: -1001234567890 (канал) или -123456789 (группа)

⚠️ Важно:

  • Для личных чатов ID всегда положительный (например: 123456789)
  • Для групп ID всегда отрицательный (например: -123456789)
  • Для каналов ID всегда с -100 в начале (например: -1001234567890)
  • Бот должен быть добавлен в группу/канал чтобы получить её ID

Browser Agent Provider

📝 Manual (Ручной режим)

Вы копируете промпт из системы и вставляете его в Codex/браузерный агент вручную. Результат также вставляется вручную.

  • Плюсы: Полный контроль, не требует настройки
  • Минусы: Требует ручного вмешательства для каждой задачи
  • Когда использовать: Для начала работы, тестирования, или если другие режимы недоступны

📋 Clipboard (Буфер обмена)

Система автоматически открывает Codex и копирует промпт в буфер обмена. Вам нужно только вставить его.

  • Плюсы: Частичная автоматизация, проще чем manual
  • Минусы: Все еще требует ручного вставления и запуска
  • Когда использовать: Если хотите немного упростить процесс

🌐 Browser Bridge (Браузерный мост)

Система использует Playwright для управления браузером с уже активной сессией Codex. Полностью автоматическая вставка промпта и получение результата.

  • Плюсы: Полная автоматизация, не требует ручного вмешательства
  • Минусы: Экспериментальный режим, требует настройки, может быть нестабильным
  • Когда использовать: Для продакшена, когда нужна полная автоматизация
  • Требования: Установленный Playwright, настроенный профиль браузера

🔌 API (Внешний API)

Использование внешнего API для взаимодействия с браузерным агентом (если доступен).

  • Плюсы: Интеграция с внешними сервисами
  • Минусы: Требует доступного API endpoint
  • Когда использовать: Если у вас есть совместимый API сервис

Рекомендация: Начните с Manual режима для знакомства с системой. Для продакшена настройте Browser Bridge.
